
# Personal Introduction Program

## Project Overview
This is a beginner Python project that collects personal
information and displays a personalized welcome message.

## Objectives
- Learn variables and data types.
- Practice input() and print().
- Understand strings and f-strings.
- Practice lists and basic arithmetic.
- Learn to organize a Python project.

## Technologies Used
- Python 3
- Visual Studio Code
- GitHub

## Setup Instructions
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run: python personal_intro.py
6. Enter the requested information.

## Files
- personal_intro.py: Main Python program.
- README.md: Project documentation.
- requirements.txt: Dependency information.
- screenshot.png: Program output screenshot.

## What I Learned
I learned how to use variables, user input, strings,
lists, f-strings, comments, and basic arithmetic.

## Testing
The program was tested with different names, ages,
cities, hobbies, and favorite foods.
